# Palabrix

An offline Spanish mini-crossword app built with Expo (iOS, Android, web). No backend; progress is stored on the device.

## Run

```bash
npm install
npm run web      # browser
npm run ios      # iOS simulator
npm run android  # Android emulator
```

## Test

```bash
npm run typecheck
npm test
```

See `docs/superpowers/specs/` for the design and `docs/superpowers/plans/` for the implementation plan.
